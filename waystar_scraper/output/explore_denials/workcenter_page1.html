  1. Welcome to the new My Work Screen!

    Welcome to the new My Work Screen! We’ve redesigned the screen to display ALL results within a workgroup, no matter how large the workgroup. Additional changes include a simplified Search & Filter section and a more robust 'More Filters' section for advanced filtering.

  2. Results

    The My Work page now displays ALL results within the workgroup, not just the top 1,000 based on the current sort. In addition, all Search or Filter options will include all denials within the workgroup.

  3. Search/Filter

    The Search & Filter control is simpler, highlighting the most frequently used search options (Patient Name & Claim #) and the most used filters (Payer, Account, Workflow Stage and Category).

    The Payer and Account filters utilize type-ahead technology to find the correct result. The Workflow Stage and Category filters contain static drop downs, but do allow multiple selections.

  4. More Filters

    If there is a filter or search that you cannot access on the page, please reference the "More Filters" link for a comprehensive list of available options.

    When you click on "More Filters" all Search and Filter options will be present on this screen. Certain options include a new 'Search' feature, which helps quickly identify the desired value.

  5. Batch Appeals

    Denials can now be submitted for appeal in groups of up to 100 denials. The Appeal Wizard was redesigned from the ground up to handle multiple appeals at the same time.
