  1. Welcome to the new Review Screen

    Welcome to the new Review Screen! We’ve redesigned the screen to allow users to clearly see all relevant information related to the denial in a more friendly format.

    The key changes include displaying more relevant information pertaining to the denial, making it easier to see which remits have active adjustments, and creating a customizable timeline of events in the Activity History tab.

  2. Details & Insurance

    The left hand panel highlights patient and insurance details pertaining to the denial. This includes new data elements surrounding the Denial Age, Child Account, and patient insurance details like Member ID and Group Number.

  3. Workflow

    The center panel highlights a new Workflow section, which displays the Category, Current Workflow Stage, Days in Stage and Workgroup, so users can easily see where this denial belongs in My Work.

  4. Summary

    The center panel includes the familiar Summary section, with a minor design tweak to better highlight the Current Denial Amount and Additional Payment collected on the denial.

  5. Remits

    Finally, the center panel focuses the user’s attention on the Remits that contain active adjustments that need to be worked. By default, closed remits and closed procedure lines will be collapsed, but can be expanded if needed. The table layout for the Remit is also new, to better align with how the data correlates on the actual Explanation of Benefits.

  6. Activity History

    This new tab, which replaces the previous ‘Breakdown’ section, allows the user to see a quick timeline view of all Claim, Remit and user activity performed on the denial over time.

    The user can dictate whether they want to see the activity chronologically from Oldest to Newest or vice versa.

  7. Related Denials

    This new tab, which replaces the previous Merge Denials option, allows the user to see all denials for the same patient in a centralized location.

    Denials marked with the 'Possible Merge' label match the current denial on some but not all key data fields. With Related Denials, users can view all denials for the patient and work them together.
